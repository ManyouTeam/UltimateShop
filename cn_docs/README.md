## 插件介绍

* UltimateShop 是一款功能强大的 Spigot 商店插件，致力于整合各类付费商店插件的功能。
* 商品与价格支持多对多关系，并可通过条件系统自由控制。例如，让玩家支付 500 积分和一组钻石，换取一把强力钻石剑与 5 天 VIP 权限组，在 UltimateShop 中就能轻松实现。
* 支持按交易次数应用价格，使玩家每次购买同一商品时支付不同价格。
* 动态价格系统模拟现实中的价格变化：每位玩家的购买或出售操作都可以影响商品价格。
* 支持玩家个人和全服的交易上限或库存，并内置自动重置功能，用于补充库存。
* 内置物品格式，可配置自定义食物、工具、属性、盔甲等各种物品。
* 内置强大的菜单系统，可制作商店菜单、通用菜单和批量购买菜单。付费版还能自动将 Java 菜单转换为 Bedrock 表单 UI，无需额外修改。
* 内置动作与条件系统，突破仅依赖命令和权限的限制，并且几乎可以在插件的各个位置使用。
* 内置数学、随机、比较、折扣等占位符，并支持通过 PlaceholderAPI 展示商品占位符。（付费版）
* 所有数值选项均支持动态数值或表达式。可以在数值配置中使用占位符和数学运算，实现动态库存、商品数量、价格等，也可以让价格随玩家等级变化。
* 支持众多自定义物品插件和经济插件。即使对接物品的描述或显示名称发生变化，UltimateShop 也能正确识别。
* 高度灵活的配置支持动态价格、现实库存、季节性价格、轮换商品、每日商店、货币兑换、每日奖励、连续签到奖励、命令商店、刷怪笼商店等各种玩法。
* 可自由设置商店点击事件，例如左键出售一组、右键购买一个；还可自定义价格说明以及出售商品时的物品匹配规则。
* 商品支持子按钮，可在多个位置展示同一商品，用于制作类似村民交易界面的商店 GUI。
* 自定义价格功能允许接入插件尚未直接支持的经济或物品插件。（付费版）
* 智能物品发放方式会自动合并玩家购买的物品，并计算物品栏剩余空间。（需在 `config.yml` 中启用）
* 针对常见用途，Wiki 提供了配置示例；部分自动设置还可帮助简化配置。
* 在插件消息和占位符等位置自动翻译原版物品名称，无需为每件原版商品手动设置名称。（需要 1.16+ 服务器和付费版）
* 内置出售棒和全部出售 GUI，无需安装其他附属插件。（出售棒需要付费版）
* 还有更多其他功能……
