# ✅运行要求

## Java 版本

* 最低要求：**Java 16+**。
* <mark style="color:red;">推荐</mark>使用 **Java 17+**。插件使用 **Java 16** 编译，因此理论上 Java 16 及以上即可运行，但仍建议使用 Java 17 或更高版本。

## 服务器核心

| 核心 | 能否运行 | 是否提供官方支持 |
| --- | --- | --- |
| Spigot | <p>✅<br>部分功能在 Spigot 服务器上不可用。</p> | ✅ |
| Paper/Purpur | <p>✅<br>可带来少量性能提升。</p> | ✅ |
| Folia | <p>❓<br>仅在 Folia 上出现的问题可能不会得到解决。插件并非针对多线程环境设计。</p> | <p>❓</p><p>Folia 支持尚处于<mark style="color:red;">早期测试阶段</mark>，未来可能正式提供，也可能移除，因此不作支持保证。</p> |
| 其他核心 | ❌ | ❌ |

## 服务器版本

| 版本 | 能否运行 | 是否提供官方支持 |
| --- | --- | --- |
| **低于 1.14** | ❌ | ❌ |
| **1.14 \~ 1.20.4** | <p>❓<br>插件可以运行，但不会处理这些版本导致的问题。</p> | ❌ |
| **1.20.5 及以上** | <p>✅<br>最推荐使用 <strong>1.21.5</strong> 及以上版本，以获得最完整的功能体验。</p> | ✅ |

* 如果在某个版本上遇到错误，请<mark style="color:red;">加入我们的 Discord 反馈</mark>。

## 使用自定义货币时还需要经济插件

* **UltimateShop** 仅提供商店功能，不负责创建自定义经济系统。如果服务器需要自定义货币，请自行选择合适的经济插件。**Vault** 也不是经济插件，而是许多经济插件所依赖的接口插件。<mark style="color:red;">安装 Vault 后，还必须安装支持 Vault 的经济插件</mark>。
