# ⚙️安装

## 安装步骤

* 将 `.jar` 文件放入服务器的 `plugins` 文件夹。
* 关闭服务器后重新启动。<mark style="color:red;">插件必须随服务器启动加载，不得通过其他方式加载</mark>。
* 更新插件时，务必移除旧版本。
* 从免费版升级到付费版时，只需安装付费版并移除免费版，无需修改配置文件。
* 如果服务器从**较新的游戏版本**降级到**较旧版本**，务必删除插件配置目录中的 `items` 文件夹。
* 使用[物品名称本地化](../features/localized-item-name-premium.md)功能时，切换服务器游戏版本后，需要删除之前生成的本地化文件。
* **UltimateShop** 仅提供商店功能，不提供自定义经济系统。若服务器需要自定义货币，请自行选择合适的经济插件。**Vault** 不是经济插件，而是许多经济插件所依赖的接口插件。<mark style="color:red;">安装 Vault 后，还必须安装支持 Vault 的经济插件</mark>。
* 默认配置用于帮助理解配置结构，请根据自己的实际需求修改。
