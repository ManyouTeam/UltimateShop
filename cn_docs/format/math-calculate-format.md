# ➗数学计算格式

和多数插件不同，UltimateShop 允许在几乎所有填数字的地方使用 PlaceholderAPI 和数学计算格式，价格、购买/出售次数上限之类都能随心配置。

{% hint style="info" %}
使用该功能需先在 `config.yml` 中开启 `math.enabled`。
{% endhint %}

<a id="result-precision"></a>

## 结果精度

`math.scale` 控制数学结果保留几位小数，UltimateShop 采用 `HALF_UP` 舍入。乘倍率同样算一次数学计算，所以乘出来的结果（包括出售价格修正、预览和最终收益）也按这个位数处理。

```yaml
math:
  scale: 2
```

例如 `scale: 2` 时，`10` 乘以 `0.333333` 得到 `3.33`。

## 数学计算格式一览

`()` - 括号，里面的内容优先计算 (`3 * (4 + 1)`)

`$` - 声明变量 (`$1 / 3`)

`e` - 欧拉常数 (`log(e)`)

`pi` - 圆周率 (`sin(pi)`)

`+` - 两数相加 (`1 + 1`)

`-` - 两数相减，或对一个数取负 (`3-2`、`-(4+2)`)

`/` - 两数相除 (`3 / 4`)

`*` - 两数相乘 (`2 * 3`)

`^` - 求幂 (`3^3`)

`%` - 取模（相除的余数） (`7 % 4`)

`abs` - 取数字的绝对值 (`abs$1`, `abs-1`)

`round` - 四舍五入到最接近的整数（`round1.5`、`round(2.3)`）

`ceil` - 向上取整 (`ceil1.05`)

`floor` - 向下取整 (`floor0.95`)

`rand` - 生成 0 到指定上限之间的随机数 (`rand4`)

`log` - 取自然对数 (`log(e)`)

`sqrt` - 取平方根 (`sqrt4`)

`cbrt` - 取立方根 (`cbrt(8)`)

`sin` - 取正弦 (`sin$2`)

`cos` - 取余弦 (`cos(2*pi)`)

`tan` - 取正切 (`tanpi`)

`asin` - 取反正弦 (`asin$2`)

`acos` - 取反余弦 (`acos0.45`)

`atan` - 取反正切 (`atan1`)

`sinh` - 取双曲正弦 (`sinh(4)`)

`cosh` - 取双曲余弦 (`cosh(4)`)

`true` - 代表 1 的布尔常量

`false` - 代表 0 的布尔常量

`=` - 判断两数是否相等（`1 = 1` 得 `1`，`1 = 3` 得 `0`），也可写作 `==`

`!=` - 判断两数是否不等（`1 != 2` 得 `1`，`1 != 1` 得 `0`）

`>` - 判断前者是否大于后者 (`1 > 0`)

`<` - 判断前者是否小于后者 (`0 < 1`)

`>=` - 判断前者是否大于或等于后者 (`1 >= 1`)

`<=` - 判断前者是否小于或等于后者 (`0 <= 1`)

`|` - 逻辑或 (`true | false`)，也可写作 `||`

`&` - 逻辑与 (`true & true`)，也可写作 `&&`

`!` - 逻辑非 (`!true`)

## 函数

下表所有函数都需要同时开启 `math.enabled: true` 和 `math.enable-function: true`，包括 `piecewise()`。

| 函数 | 返回值 | 示例 |
| --- | --- | --- |
| `sum(...)` | 所有参数之和 | `sum(1, 2, 3)` → `6` |
| `max(...)` | 最大值 | `max(5, 12, 8)` → `12` |
| `min(...)` | 最小值 | `min(5, 12, 8)` → `5` |
| `avg(...)` | 平均值 | `avg(10, 20, 30)` → `20` |
| `random(...)` | 在指定范围内取随机小数 | `random(2, 5)` → 大于等于 2、小于 5 |
| `piecewise(...)` | 取第一个成立条件对应的值 | `piecewise(3 < 5, 10, 20)` → `10` |

`sum`、`max`、`min` 和 `avg` 不传参数时都返回 `0`。

### 随机数

- `random()` 返回 0 到 1 之间的小数。
- `random(4)` 的范围是 0 到 4。传负数时，例如 `random(-4)`，范围是 -4 到 0。
- `random(2, 5)` 的范围是 2 到 5。两个端点可以交换顺序，第三个及之后的参数会被忽略。

范围包含下限，上限不包含在内。两个端点相同时直接返回该值，所以 `random(0)` 返回 0，`random(5, 5)` 返回 5。

### 分段计算

`piecewise(条件1, 值1, 条件2, 值2, 默认值)` 返回第一个成立条件对应的值，条件都不成立就返回默认值。例如 `piecewise(3 < 5, 10, 20)` 返回 10。引擎会先计算所有参数，所以各个分支都要写成能正常求值的表达式。

想看 `min`、`max`、`log` 和 `floor` 一起使用的例子，可参考[动态价格 YAML](../dynamic-prices/dynamic-price.md#按比例跌价的完整配置)。
