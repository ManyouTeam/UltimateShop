# 🎨颜色代码

UltimateShop 提供两种颜色代码格式，会自动识别所使用的格式，无需额外设置。

## MiniMessage

* 格式说明见[这里](https://docs.advntr.dev/minimessage/format.html)。
* 需要 Paper 或其分支，且服务器版本至少为 1.17.1。
* 支持字体、悬停文本等高级功能。
* 几乎可以在所有位置使用。

## 内置颜色解析器

* 格式：
  * 十六进制颜色使用 **`&#十六进制颜色代码`**。
  * 例如 `&#ff0000`。
  * 渐变色使用 **`&<#起始颜色代码> 文本 &<#结束颜色代码>`**。
  * 例如 `&<#666666>UltimateShop &<#ffffff>`。
  * 普通颜色代码例如 `&b`。
  * 低于 1.16 的版本会自动将十六进制颜色转换为普通颜色。
* 支持所有版本和服务器核心。
* 仅提供常用颜色功能。
* 可在所有位置使用。
* 对于符合 MiniMessage 运行要求的 Paper 服务器，插件会自动将内置颜色格式转换为 MiniMessage 格式。
